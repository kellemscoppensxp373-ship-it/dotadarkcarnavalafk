# Инструкция: что делать дальше

Коротко: **программа готова, но одну таблицу должны заполнить вы** — какой герой даёт
3 билета для каждого аркана. Это 5 минут, и без этого агент осознанно не запустится.

## 0. Самое важное: почему я не заполнил героев за вас

Вы прислали 11 скриншотов — ШУТ, МАГ, ВЕРХОВНАЯ ЖРИЦА, ИМПЕРАТОР, ВЛЮБЛЁННЫЕ, СИЛА,
ОТШЕЛЬНИК, КОЛЕСО ФОРТУНЫ, СМЕРТЬ, ДЬЯВОЛ, ЗВЕЗДА. Структуру я разобрал точно:

```
┌─ верхняя секция ─┐  много героев   → 1 билет за игру
├─ средняя секция ─┤  меньше героев  → 2 билета
└─ нижняя секция ──┘  обычно 1 герой → 3 билета   ← только это и нужно
```

А вот **опознать героев по пиксельным иконкам 35×35 нельзя** — ни мне, ни любому
автомату без эталонных спрайтов. Если бы я «угадал», бот молча фармил бы не тех героев
и вы потеряли бы десятки игр. Поэтому имена вводите вы — один раз, в интерфейсе.

> Хотите, чтобы заполнил я? Напишите списком: «СМЕРТЬ — Фантом Ассасин, ШУТ — Лина, …»,
> и я зашью это в репозиторий значениями по умолчанию.

## 2. Установка (если запускаете из исходников)

Нужен **Python 3.12+** (при установке обязательно галочка *Add Python to PATH*).

```powershell
cd dotadarkcarnavalafk
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

При первом запуске EasyOCR скачает русскую модель (~100 МБ), это один раз.
Если нет видеокарты NVIDIA — снимите галочку «Использовать видеокарту для EasyOCR».

## 3. Настройки Dota 2 — обязательно

| Параметр | Значение | Зачем |
|---|---|---|
| Язык | Русский | Агент читает именно русские надписи |
| Режим экрана | **Оконный без рамки** | В эксклюзивном полноэкранном захват экрана не работает |
| Разрешение | Любое, но постоянное | Разметка экрана в долях, но PNG-спрайты привязаны к разрешению |
| Масштаб Windows | 100 % | Иначе координаты «поедут» |

## 4. Заполнить вкладку «Билеты» — без этого агент не стартует

1. Запустите программу → вкладка **«Билеты»**.
2. В игре откройте панель нужного аркана (например, **СМЕРТЬ**).
3. Посмотрите, кто стоит в **нижней секции** (три значка билета).
4. Впишите имя героя **так, как оно пишется в поиске героев Dota по-русски**
   (например, `Фантом Ассасин`). Если героев несколько — через запятую, агент будет
   их чередовать.
5. В колонке **«Нужно билетов»** поставьте, сколько хотите нафармить
   (`0` = этот аркан не трогать). Агент сам остановится по достижении цели.
6. Нажмите **«Сохранить таблицу билетов»**.

Заполнять все 11 не обязательно — достаточно тех арканов, которые вам нужны.
Внизу видно: «Заполнено арканов: N из 11».

Всё хранится в `data/tickets.json`, его можно править и руками:

```json
{
  "min_yield": 3,
  "arcana": {
    "death": { "name_ru": "СМЕРТЬ", "x3": ["Фантом Ассасин"], "x2": [], "x1": [] }
  }
}
```

> **Почему только ×3?** Игра на «тройном» герое занимает столько же времени, сколько на
> «одиночном», но приносит втрое больше билетов. Параметр «Минимум билетов за игру» на
> вкладке «Управление» стоит на `3` — герои с меньшей отдачей просто игнорируются.
> Опускать его до 2 или 1 имеет смысл, только если для нужного аркана вы не нашли ×3.

## 5. Первый запуск — обязательно в симуляции

Галочка **«Режим симуляции»** включена по умолчанию: агент смотрит, думает и пишет в
журнал, но **мышь и клавиатуру не трогает**.

1. Зайдите в Dota, встаньте в главное меню.
2. Нажмите **«Старт»**.
3. Смотрите журнал. Должны появляться строки вида:
   ```
   состояние: неизвестный экран → главное меню
   клик «Играть» @(1600, 980) (сходство 1.00)
   цикл 1: Фантом Ассасин → 3 бил. аркана «СМЕРТЬ»
   ```
4. Если состояния определяются правильно — выключайте симуляцию и запускайте
   по-настоящему.

**F12 — аварийная остановка в любой момент.** Ещё одна страховка: резкое движение мышью
в левый верхний угол экрана (PyAutoGUI FAILSAFE).

## 6. Если агент «не видит» экран

| Симптом | Что сделать |
|---|---|
| «экран не опознан» | Dota точно в оконном без рамки? Язык русский? |
| Ничего не находит | Вкладка «Управление» → снизить «Порог распознавания» до `0.70` |
| Кликает не туда | Наоборот, поднять порог до `0.85` |
| Мелкий текст не читается | В `scripts/vision.py` увеличить `upscale` до `2.0` |
| Хочу увидеть, что видит бот | В журнале при повторных сбоях агент сам печатает полный список распознанного текста |

## 7. Необязательно: спрайты героев

Программа работает **без единого PNG** — герой ищется по имени и подтверждается чтением
названия в сетке выбора. Спрайты лишь ускоряют и уточняют:

* `assets/portraits/portrait_*.png` — 3D-портрет из сетки выбора героя;
* `assets/emoji/emoji_*.png` — пиксельная иконка с экрана наград (сверка начисления).

Как нарезать — в `assets/README.md`. Имена файлов берутся из `HERO_DB`
(`scripts/dota_logic.py`).

## 8. Как менять логику без пересборки .exe

Это главная фишка архитектуры — вся логика лежит обычными `.py` рядом с программой.

* **Вкладка «Консоль разработчика»** → выбрать скрипт → «Открыть файл в редакторе» →
  поправить → **«Применить и перезагрузить»**. Изменения вступают в силу мгновенно.
  Код с синтаксической ошибкой не применится, а если модуль упадёт при импорте —
  автоматически откатится на прошлую версию. Кнопка «Откатить» — вручную.
* **Вкладка «Обновление с GitHub»** → указать владельца/репозиторий/ветку →
  **«Скачать с GitHub и применить»**. Я правлю код в репозитории, вы жмёте одну кнопку —
  пересобирать `.exe` не нужно.
